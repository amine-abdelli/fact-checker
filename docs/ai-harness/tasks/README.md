# Task briefs

One file per unit of work: `T-<id>-<slug>.md`. `T-0xx` = decisions and setup, `T-1xx` = Phase 1
pipeline, `T-2xx` = Phase 2 UI, `T-3xx` = Phase 3 quality.

A brief is ready when its acceptance criteria can be checked by someone who did not write it.
Write one with `/plumb-task`. The format is in the `plumb-harness` skill.
